## Reglas del proyecto

- Idiomas: español e inglés.
- Tamaño recomendado durante gameplay: 16 px o superior.
- Tamaño mínimo excepcional: 14 px.
- Mantener escalado entero y evitar suavizado visual cuando se busque una lectura pixel-art estricta.
- Los textos permanecen fuera de los PNG y se cargan según el idioma seleccionado.
- Conservar caracteres españoles: ¿? ¡! ÁÉÍÓÚ áéíóú Ññ Üü.

El archivo local evita depender de Google Fonts o de otra red durante la ejecución del demo.
