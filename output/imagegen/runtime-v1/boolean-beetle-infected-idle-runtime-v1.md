# Boolean Beetle infectado — Idle runtime v1

## Alcance del demo

Este minion infectado solo requiere el estado de reposo para la secuencia final.
No se producirán desplazamiento, ataques, daño ni derrota.

## Archivo

- Imagen: `boolean-beetle-infected-idle-runtime-v1.png`
- Tamaño total: 384 × 512 px
- Retícula lógica: 3 columnas × 4 filas
- Tamaño de celda: 128 × 128 px
- Fondo: transparencia real, alfa binario
- Sombra: ninguna

## Direcciones

1. Frente / abajo
2. Izquierda
3. Derecha
4. Espalda / arriba

La fila derecha es el espejo horizontal exacto de la fila izquierda.

## Ciclo de reposo

1. Pulso carmesí bajo y asentamiento del caparazón.
2. Reposo pesado controlado neutral.
3. Pulso alto a través del nodo central, puertos fúngicos y articulaciones.

## Identidad infectada

- Se conservan el caparazón cerrado y las seis patas.
- El volumen pesado de Boolean Beetle permanece intacto.
- El reactor lógico central fue sustituido por un nodo carmesí.
- Pequeños puertos fúngicos perforan visualmente el caparazón.
- Vetas de micelio marfil contaminan los canales TRUE y FALSE.
- Los canales cian y naranja permanecen claramente reconocibles.
- No hay cable externo dentro de esta hoja.

## Validación

- Dimensiones verificadas.
- Alfa binario: únicamente 0 y 255.
- Línea base constante en Y=117.
- Simetría lateral exacta.
- Escala compatible con `boolean-beetle-idle-runtime-v1.png`.
- Márgenes seguros y caparazón sin recortes.
- Sin apertura del caparazón, alas, ataques, movimiento, daño o derrota.

## Prompt de generación

Reposo infectado de Boolean Beetle para la secuencia final del demo. Se utilizó
el reposo original como referencia estricta de identidad y Dependency Takeover
como referencia de infección. Se solicitaron nodo lógico carmesí, puertos
fúngicos, micelio marfil y conservación de los canales cian y naranja. La
fuente se generó con la herramienta integrada sobre fondo `#FF00FF` y se
convirtió posteriormente a transparencia alfa.
