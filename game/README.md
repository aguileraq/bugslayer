# BugSlayer game

Scaffold ejecutable definido por SPEC-001 y TASK-101.

## Entorno fijado

- Node.js 24.19.0 LTS
- npm 11.18.0

## Validación local

Desde esta carpeta, instalar con `npm ci` y ejecutar `npm run check`. El servidor
de desarrollo se inicia con `npm run dev`.

La pantalla actual es únicamente un diagnóstico del scaffold. Boot, selección
de idioma y menú se implementan en sus tareas específicas.
