# Mycelial Monolith — Spore Injection projectile runtime v1

## Archivo

- Imagen: `mycelial-monolith-spore-injection-projectile-runtime-v1.png`
- Tamaño total: 96 × 128 px
- Retícula lógica: 3 columnas × 4 filas
- Tamaño de celda: 32 × 32 px
- Fondo: transparencia real, alfa binario
- Sombra: ninguna

## Direcciones

1. Abajo / hacia el jugador
2. Izquierda
3. Derecha
4. Arriba / alejándose

Las direcciones opuestas usan transformaciones exactas para impedir cambios de
escala o silueta.

## Ciclo de vuelo

1. Pulso comprimido.
2. Núcleo expandido y luminoso.
3. Contracción y retorno.

## Identidad visual

- Cápsula mecánico-fúngica compacta.
- Carcasa segmentada de grafito.
- Costillas y caparazón de micelio marfil.
- Núcleo naranja-blanco.
- Poros borgoña.
- Estela energética muy corta.

## Validación

- Dimensiones verificadas.
- Alfa binario: únicamente 0 y 255.
- Márgenes internos seguros.
- Ningún proyectil queda cortado.
- Derecha es espejo exacto de izquierda.
- Arriba es rotación exacta de abajo.
- Sin grid, texto, sombra o fondo residual.

## Prompt de generación

Proyectil en vuelo para Spore Injection basado en la identidad visual aprobada
de Mycelial Monolith: semilla mecánico-fúngica con carcasa oscura, micelio
marfil y núcleo naranja. Se solicitaron cuatro direcciones, tres pulsos y fondo
uniforme `#FF00FF`, convertido después a transparencia alfa.
