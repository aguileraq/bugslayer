# Mutable Widow infectada — Idle runtime v1

## Alcance del demo

Este minion infectado solo requiere el estado de reposo para la secuencia final.
No se producirán movimiento, ataques, daño ni derrota.

## Archivo

- Imagen: `mutable-widow-infected-idle-runtime-v1.png`
- Tamaño total: 384 × 512 px
- Retícula lógica: 3 columnas × 4 filas
- Tamaño de celda: 128 × 128 px
- Fondo: transparencia real, alfa binario
- Sombra: ninguna

## Direcciones

1. Frente / abajo
2. Izquierda
3. Derecha
4. Espalda / arriba

La fila derecha es el espejo horizontal exacto de la fila izquierda.

## Ciclo de reposo

1. Pulso carmesí bajo y cuerpo ligeramente descendido.
2. Reposo controlado neutral.
3. Pulso alto a través del reactor, membrana micelial y articulaciones.

## Identidad infectada

- Se conserva el cuerpo circular y las ocho patas de Mutable Widow.
- El reactor dorsal mantiene su forma y lectura.
- Una membrana micelial marfil cubre parcialmente el reactor.
- El nodo carmesí central funciona como puerto de Dependency Takeover.
- Hifas marfil conectan reactor, articulaciones y colmillos.
- Cian y verde lima permanecen visibles como señales subordinadas.
- No hay cable externo dentro de esta hoja.

## Validación

- Dimensiones verificadas.
- Alfa binario: únicamente 0 y 255.
- Línea base constante en Y=117.
- Simetría lateral exacta.
- Escala compatible con `mutable-widow-idle-runtime-v1.png`.
- Márgenes seguros y ausencia de extremidades cortadas.
- Sin web, ataques, proyectiles, movimiento, daño, derrota o sombra.

## Prompt de generación

Reposo infectado de Mutable Widow para la secuencia final del demo. Se utilizó
el reposo original como referencia estricta de identidad y Dependency Takeover
como referencia de infección. Se solicitaron membrana micelial marfil, nodo
carmesí, hifas hacia las patas y colmillos, y señales cian/verde lima
subordinadas. La fuente se generó con la herramienta integrada sobre fondo
`#FF00FF` y se convirtió posteriormente a transparencia alfa.
