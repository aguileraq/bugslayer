# Geist Pixel Square — estándar tipográfico runtime v1

## Uso aprobado

- Fuente principal: Geist Pixel Square.
- Idiomas: español e inglés.
- Títulos principales: 32 px.
- Subtítulos y encabezados de sección: 24 px.
- Diálogo: 20 px.
- HUD, botones, opciones y campos: 16 px.
- Tamaño mínimo excepcional: 14 px.

## Jerarquía de color

- Primario: cian, para foco, selección y etiquetas activas.
- Sistema: blanco o gris azulado, para información neutral.
- Peligro: rojo, para enemigo, daño, error y derrota.
- Tiempo: ámbar, reservado para el temporizador y avisos de tiempo.

## Reglas de legibilidad

- Texto alineado a píxeles enteros y sin suavizado.
- No estirar ni comprimir la fuente.
- Mantener alto contraste sobre panel azul marino o negro.
- Evitar párrafos largos en mayúsculas.
- No bajar de 14 px; 16 px es el mínimo recomendado durante gameplay.
- Validar siempre signos y caracteres: ¿? ¡! ÁÉÍÓÚ áéíóú Ññ Üü.
- Mantener nombres de operadores y fragmentos de código sin traducción.

## Aplicaciones validadas

- Diálogos narrativos del Senior Engineer y V4LK.
- Indicadores compactos de HUD.
- Preguntas bilingües de opción múltiple.
- Captura de respuesta y contador de caracteres.
- Temporizador de desafío.

## Nota de integración

Para el build final se recomienda incluir localmente el archivo WOFF2 oficial de Geist Pixel Square, evitando una dependencia de red durante el demo.
