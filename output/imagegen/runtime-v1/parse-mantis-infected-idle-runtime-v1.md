# Parse Mantis infectado — Idle runtime v1

## Alcance del demo

Este minion infectado solo requiere el estado de reposo para la secuencia final.
No se producirán movimiento, ataques, daño ni derrota.

## Archivo

- Imagen: `parse-mantis-infected-idle-runtime-v1.png`
- Tamaño total: 384 × 512 px
- Retícula lógica: 3 columnas × 4 filas
- Tamaño de celda: 128 × 128 px
- Fondo: transparencia real, alfa binario
- Sombra: ninguna

## Direcciones

1. Frente / abajo
2. Izquierda
3. Derecha
4. Espalda / arriba

La fila derecha es el espejo horizontal exacto de la fila izquierda.

## Ciclo de reposo

1. Pulso carmesí bajo y cuerpo ligeramente comprimido.
2. Reposo controlado neutral.
3. Pulso carmesí alto en ojo, articulaciones y puerto dorsal.

## Identidad infectada

- Se conserva la silueta, anatomía y volumen de Parse Mantis.
- Se conservan las dos placas dorsales y las pinzas frontales.
- El micelio marfil invade las placas dorsales.
- El ojo y algunas articulaciones funcionan como nodos carmesí.
- Un puerto circular dorsal permite la conexión visual con Dependency Takeover.
- El naranja original permanece como energía residual subordinada.
- No hay cable externo dentro de esta hoja.

## Validación

- Dimensiones verificadas.
- Alfa binario: únicamente 0 y 255.
- Línea base constante en Y=117.
- Simetría lateral exacta.
- Escala compatible con `parse-mantis-idle-runtime-v1.png`.
- Márgenes seguros y ausencia de extremidades cortadas.
- Sin ataques, proyectiles, movimiento, daño, derrota, sombra o fondo residual.

## Prompt de generación

Reposo infectado de Parse Mantis para la secuencia final del demo. Se utilizó el
reposo original como referencia estricta de identidad y Dependency Takeover
como referencia de infección. Se solicitaron micelio marfil, nodos carmesí,
puerto dorsal y energía naranja residual, en cuatro direcciones y tres pulsos.
La fuente se generó con la herramienta integrada sobre fondo `#FF00FF` y se
convirtió posteriormente a transparencia alfa.
