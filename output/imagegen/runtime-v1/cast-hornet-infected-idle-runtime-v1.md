# Cast Hornet infectado — Idle runtime v1

## Alcance del demo

Este minion infectado solo requiere el estado de reposo aéreo para la secuencia
final. No se producirán desplazamiento, ataques, daño ni derrota.

## Archivo

- Imagen: `cast-hornet-infected-idle-runtime-v1.png`
- Tamaño total: 384 × 512 px
- Retícula lógica: 3 columnas × 4 filas
- Tamaño de celda: 128 × 128 px
- Fondo: transparencia real, alfa binario
- Sombra: ninguna

## Direcciones

1. Frente / abajo
2. Izquierda
3. Derecha
4. Espalda / arriba

La fila derecha es el espejo horizontal exacto de la fila izquierda.

## Ciclo de reposo

1. Pulso carmesí bajo con alas ligeramente descendidas.
2. Hover controlado neutral.
3. Pulso alto a través del nodo dorsal, raíces de ala y venas miceliales.

## Identidad infectada

- Se conservan cuatro alas, seis patas y un aguijón.
- El abdomen mecánico segmentado mantiene su forma original.
- Venas de micelio marfil atraviesan las alas cian.
- Un nodo carmesí dorsal funciona como puerto de Dependency Takeover.
- Las raíces de ala, articulaciones y ojos muestran pulsos carmesí.
- Los canales cian, amarillo y violeta permanecen visibles pero subordinados.
- No hay cable externo ni esporas sueltas dentro de esta hoja.

## Validación

- Dimensiones verificadas.
- Alfa binario: únicamente 0 y 255.
- Alturas de hover compatibles con `cast-hornet-idle-runtime-v1.png`.
- Simetría lateral exacta.
- Márgenes seguros y ausencia de alas o aguijón cortados.
- Sin desplazamiento, ataques, proyectiles, daño, derrota o sombra.

## Prompt de generación

Reposo aéreo infectado de Cast Hornet para la secuencia final del demo. Se
utilizó el reposo original como referencia estricta de identidad y Dependency
Takeover como referencia de infección. Se solicitaron venas miceliales marfil
en las cuatro alas, nodo dorsal carmesí y conservación reducida de los canales
cian, amarillo y violeta. La fuente se generó con la herramienta integrada
sobre fondo `#FF00FF` y se convirtió posteriormente a transparencia alfa.
